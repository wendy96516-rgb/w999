## 三、個人回答

### 問題一
測試一中，整理後的桌遊串列有 4 筆資料，為什麼桌遊費用應以 3 人計算？直接把字串拆成 list，和再轉成 set，各自保留了什麼、失去了什麼？

在測試一中，整理後的桌遊串列是 `['amy', 'ben', 'amy', 'cora']`，雖然有 4 筆資料，但 `'amy'` 出現了兩次；依活動規則，同一人在同一場活動重複報名只算一位參加者、只收一次費，因此實際參加桌遊體驗的不重複人數是 3 人（`'amy'`、`'ben'`、`'cora'`）[cite: 1]。

* **直接把字串拆成 `list`**：保留了原始的出現順序與重複報名紀錄，但沒有自動去重，無法直接代表實際人數或用來計算單場費用[cite: 1]。
* **再轉成 `set`**：保留了不重複的參加者元素，也方便做交集、聯集與差集比較，但會失去原本的排列順序與重複出現的次數[cite: 1]。

### 問題二
測試三中，兩場活動只有 3 位不同的人，為什麼是 6 人次、總應收仍是 600 元？請用集合關係與算式說明。

在測試三中，桌遊去重後的集合為 `{'amy', 'ben', 'cora'}`（元素個數 3），電影去重後的集合同樣為 `{'amy', 'ben', 'cora'}`（元素個數 3）[cite: 1]。兩場活動的參加者完全相同，因此：

* **聯集**為 `{'amy', 'ben', 'cora'}`，總不重複人數是 `len(聯集) = 3` 人[cite: 1]。
* **報名人次**是兩場各自去重人數相加，因為這 3 人都同時參加了兩場活動，所以是 `3 + 3 = 6` 人次[cite: 1]。
* **總應收**依各場去重人數乘上單價計算：
  * 桌遊應收：`3 × 120 = 360` 元[cite: 1]
  * 電影應收：`3 × 80 = 240` 元[cite: 1]
  * 總應收：`360 + 240 = 600` 元[cite: 1]
